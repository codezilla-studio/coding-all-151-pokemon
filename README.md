# 🦖 Coding all 151 Pokémon

Every original Pokémon, drawn with **nothing but code** – no images, no canvas, just pure CSS.
Each one is typed live, pixel by pixel, in a short video.

▶️ **Gallery:** https://codezilla-studio.github.io/coding-all-151-pokemon/

## How to use

Every file is a complete, standalone HTML page – open it in any browser, or copy the code into CodePen.

```
004-charmander.html  →  https://codezilla-studio.github.io/coding-all-151-pokemon/004-charmander.html
```

Feel free to learn from it, remix it and share it – a mention of **@codezilla.studio** is appreciated. 💚
